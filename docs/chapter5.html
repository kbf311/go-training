Chapter 05

発展とこれからの学習

Go言語の真価が発揮される領域と、初心者が陥りがちな注意点・ハマりどころ

5-1 その他Go言語でできること（Goの真骨頂）

Web API開発にとどまらず、Go言語はインフラ基盤や大規模分散システムにおいて世界中で採用されています。

🚀 並行処理（Goroutine & Channel）

go func() { ... }() と書くだけで別スレッドが立ち上がります。外部APIを100個同時に叩いて結果を集約するバッチ処理なども、数行のシンプルなコードで超高速に実現できます。

🛠 高性能なCLIツールの自作

Docker, Kubernetes, Terraform, GitHub CLI (gh) はすべてGo言語で作られています。起動が一瞬で、単一バイナリとして社内ツールを配布するのに最適です。

🌐 gRPC / マイクロサービス

Protocol Buffersを使ったバイナリ通信プロトコル（gRPC）とGoは最高の相性です。JSONに比べて通信データ量が激減し、マイクロサービス間の高速通信で業界標準となっています。

💻 クロスコンパイルの一発実行

Windowsマシン上からでも、GOOS=linux GOARCH=amd64 go build とするだけで、Linuxサーバー（AWS EC2やコンテナ）で動くバイナリが一瞬でビルドできます。

5-2 Go開発・Next.js連携での注意点・ハマりどころ

初学者が「あれ？ 動かない…」となりやすい代表的な注意点と対策です。

⚠️ 1. CORSとCookie（セッション）の組み合わせ制限

ブラウザのセキュリティ仕様上、Cookieを扱う場合（AllowCredentials: true）、Go側のCORSで AllowedOrigins: ["*"]（ワイルドカード）を指定することはできません。

// 正しい設定: 明示的にフロントエンドのオリジンを指定する
AllowedOrigins: []string{"http://localhost:3000"}

⚠️ 2. Goの「ゼロ値（Zero Value）」とJSONの omitempty

TypeScriptの undefined と異なり、Goの変数は宣言時に必ずデフォルト値（数値なら 0、文字列なら ""、boolなら false）を持ちます。

JSONタグに `json:"count,omitempty"` を付けていると、count = 0 の時にJSONフィールドごと消滅してしまい、フロントエンドで意図しない値（undefined）になる罠があります。

⚠️ 3. defer によるリソース解放忘れの防止

ファイルオープンやDBコネクション、HTTPレスポンスボディ（resp.Body）を開いた際は、開いた直後に必ず defer でクローズしましょう。

file, err := os.Open("data.txt")
if err != nil { return err }
defer file.Close() // 関数の終了時に確実に実行される

5-3 まとめと今後のステップ

Go言語は「覚えるべき文法ルールが極めて少なく、誰が書いても同じように読みやすい」という素晴らしい特徴を持っています。

Next.jsのフロントエンド開発力にGoのバックエンド構築力が加わることで、個人開発からエンタープライズ規模の堅牢なWebシステムまで、自在に開発できるようになります。
