Chapter 04

実践ハンズオン！新しい機能を作ってみる

「DBからIDが偶数のモンスターを一括削除する機能」をフルスタックで追加実装する

4-1 今回のハンズオン要件と処理シーケンス

🎯 実装ゴール

  • モンスター一覧画面に「偶数IDを一括削除」ボタンを設置する。
  • ボタンを押すと、Goの削除API（POST /api/monsters/delete-even）を呼び出す。
  • Go側で id % 2 = 0 のレコードをSQLiteから削除し、結果をJSONで返す。
  • Next.js側で一覧が自動リフレッシュされ、偶数IDのモンスターが消えていることを確認する。

4-2 【Go言語側】削除処理の作成

sqlcによるSQLクエリ定義から、Service、Handler、ルーティングまで順を追って実装します。

ステップ 1：SQLクエリの追加

backend/db/queries/monsters.sql の末尾に偶数ID削除用のSQLを追加します。 

-- backend/db/queries/monsters.sql の末尾に追加
-- name: DeleteEvenMonsters :exec
DELETE FROM monsters
WHERE id % 2 = 0;

※ sqlc コマンドを実行できる環境であれば sqlc generate を実行すると、internal/db/monsters.sql.go に DeleteEvenMonsters(ctx) 関数が自動生成されます。

ステップ 2：Repository & Service層の追加

internal/service/monster_service.go に一括削除のビジネスロジックを追加します。 

// internal/service/monster_service.go
func (s *MonsterService) DeleteEvenMonsters(ctx context.Context) error {
    // 生SQLを実行する場合の例（sqlc生成コードでも可）
    _, err := s.db.ExecContext(ctx, "DELETE FROM monsters WHERE id % 2 = 0")
    if err != nil {
        return fmt.Errorf("failed to delete even monsters: %w", err)
    }
    return nil
}

ステップ 3：Handler の実装

internal/handler/monster_handler.go にHTTPリクエストを処理するハンドラー関数を追加します。 

// internal/handler/monster_handler.go
func (h *MonsterHandler) DeleteEvenMonsters(w http.ResponseWriter, r *http.Request) {
    // サービスを呼び出して削除
    if err := h.service.DeleteEvenMonsters(r.Context()); err != nil {
        http.Error(w, `{"error":"削除に失敗しました"}`, http.StatusInternalServerError)
        return
    }

    // 成功レスポンスを返却
    w.Header().Set("Content-Type", "application/json")
    w.WriteHeader(http.StatusOK)
    w.Write([]byte(`{"message":"偶数IDのモンスターを削除しました"}`))
}

ステップ 4：ルーティングの登録

cmd/api/main.go のモンスター関連ルーティングに登録します。 

// cmd/api/main.go のルーティング定義部分

    // ... 既存のルーティング ...
    
    // ★追加: 偶数ID削除エンドポイント
    r.Post("/delete-even", monsterHandler.DeleteEvenMonsters)

4-3 【Next.js側】ボタンを作って呼び出す

フロントエンド側でAPIクライアント関数を追加し、UIにボタンを設置します。

1. APIクライアントに関数を追加

frontend/lib/api.ts の api オブジェクトに追加します。 

// frontend/lib/api.ts
export const api = {
  // ... 既存のメソッド ...

  // ★追加: 偶数ID一括削除
  async deleteEvenMonsters(): Promise<{ message: string }> {
    return request<{ message: string }>("/monsters/delete-even", {
      method: "POST",
    });
  },
};

2. 一覧画面にボタンを設置

モンスター一覧画面（frontend/app/monsters/page.tsx）の操作バーにボタンを追加します。 

// frontend/app/monsters/page.tsx 内のハンドラー
const handleDeleteEven = async () => {
  if (!confirm("本当に偶数IDのモンスターをすべて削除しますか？")) return;

  try {
    const res = await api.deleteEvenMonsters();
    alert(res.message);
    // 一覧データを再読み込み（リフレッシュ）
    loadMonsters();
  } catch (err: any) {
    alert("削除に失敗しました: " + err.message);
  }
};

// JSX部分 (ボタン)
<button
  onClick={handleDeleteEven}
  className="bg-rose-600 hover:bg-rose-700 text-white font-bold px-4 py-2 rounded-lg text-sm transition"
>
  偶数IDを一括削除
</button>

4-4 動作確認と確認ポイント

✅ 動作確認チェックリスト

  1. Goバックエンドを起動（go run ./cmd/api）
  2. Next.jsフロントエンドを起動（npm run dev）
  3. ブラウザで http://localhost:3000/monsters を開き、一覧が表示されることを確認
  4. 「偶数IDを一括削除」ボタンをクリック
  5. アラートが表示され、ID: 2, 4, 6... のモンスターが画面から消え、奇数IDだけが残れば成功！
